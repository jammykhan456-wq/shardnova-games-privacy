1. Game covered

Riftlume: Cascade Protocol — the standalone Windows PC/Electron edition and the corresponding browser version developed by ShardNova Games. This notice supplements the publisher-wide Privacy Policy.

2. Account and online services

Riftlume's reviewed game code does not require a ShardNova Games account, does not connect to a ShardNova Games gameplay server, and does not include built-in advertising or analytics libraries. Its core puzzle gameplay is designed to run locally. Distribution platforms, operating systems, and any website hosting a browser edition may independently process information as described in their respective notices.

3. Information stored locally

The game uses browser-style local storage (including in the Electron Windows application) to remember settings, high scores, saved game snapshots, achievements, lifetime progress, and player records. This is how previous runs and scores can be restored after restarting the game.

These records are saved on the player's device. They are not automatically transmitted to a ShardNova Games gameplay server by the reviewed game code. Removing local app/browser data can erase them. The browser/PWA edition may also cache game files for offline use.

4. Downloading and purchasing

If you get Riftlume from Microsoft Store or another distributor, that platform handles the purchase, download, licensing, and any platform account services according to its own privacy terms. ShardNova Games does not receive your full card number through Riftlume's gameplay code.

5. Support and your choices

To manage local progress, use game options when available or clear the application's stored data. Clearing data may permanently remove saves. If you send a support email, we process the information you voluntarily provide under the publisher's support information practices.

Privacy and support contact: shardnovagames.support@gmail.com

Please include the game title in your message so we can respond appropriately.

6. Additional features and policy updates

If Riftlume later adds player accounts, remote/cloud saves, analytics, ads, or multiplayer, this notice must be updated before release to describe those features and any new processing. Effective date: 26 October 2026.
